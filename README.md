# HIVE 协作写作

HIVE 是一款本地 Markdown 写作工具。你可以自己写作，也可以让 AI 帮你讨论想法、整理大纲、修改选中的文字，或接着往下写。AI 的修改会先交给你审阅，采纳后才进入正文。

## 可以做什么

- **管理和编辑文档**：标题标签旁的「＋」打开新标签页，可新建笔记或查找当前空间的文件；支持行内改名、拖拽排序或移入文件夹、右键管理；可按文件名、编辑时间、创建时间或独立的自定义顺序排列。文档区底部打开回收站，可恢复文件，或预览并确认永久清理 7／15／30／90 天以前删除的条目。
- **与 AI 一起写作**：讨论想法、按大纲节点完成、轻量修改、往下续写；可把文件或文件夹拖入「依据」，上下排列参考优先级。
- **管理模型连接**：按服务管理接口与模型，手动添加模型；聊天区可搜索、按服务选择模型，并用滑条调整推理强度（以模型支持为准）。
- **标注具体片段**：点击底部标注工具，再在正文或草稿中选中文字，即可填写要求；表格可跨单元格拖选一行、一列、矩形或整表，一次填写和发送整批要求。右键取消所选范围的标记，保留正文。已有标注通过贴近文字的常驻气泡点击展开、再次点击收起；设置 → 功能可选择气泡在左、右、上、下方。再次点击工具或按 Esc 退出。
- **整理思路**：用独立写作大纲安排内容，用草稿面板随手记录。
- **笔记属性**：从顶部「插入 → 插入笔记属性」，或正文右上角的三横面板菜单打开属性编辑，选择常用属性或填写自定义字段；新建或已有属性均可点击左侧类型图标，选择文本、数字、复选框、日期、日期与时间、列表或 YAML，保存在笔记顶部。
- **插入内容**：从「插入」添加图片或表格。图片自动放入文档同级的同名 `pic` 文件夹，并以相对路径引用。
- **直接编辑表格**：实时预览中点击单元格即可编辑，保持表格排版；拖动网格线调整列宽和行高。尺寸仅保存在本机视图中，不写入 Markdown；完整源码仍可从显示模式打开。
- **显示数学公式**：正文支持 `$...$` 行内公式和 `$$...$$` 块公式，可显示分式、求和、积分和矩阵。点击公式编辑原始 LaTeX，源码模式保留 Markdown；超限或不支持的公式显示提示并保留源码。代码、普通金额和表格单元格不会被替换成公式。
- **选区快捷操作**：选中文字后右键，顶部横排提供剪切、复制、粘贴和纯文本粘贴。标注要求窗默认在气泡下方展开，顶部留白可自由拖动。
- **阅读与导航**：默认实时预览 Markdown 排版，编辑当前行时显示语法标记；右上角「显示模式」可切换完整源码、独立开启打字机模式；旁边三横面板菜单中的「标题目录」可打开或关闭目录。目录随正文更新，点击标题跳转。
- **调整工作空间**：正文始终保留一个固定主版面，可向四个方向拆分，额外正文可浮动。工具面板可拖动分栏、组合为标签，或收纳到左右图标栏；单击图标在旁边展开。右上角小锁固定停靠区位置，仍可打开和收纳面板。设置可调整文字、UI 大小、顶部编辑栏和写作底栏，也可关闭底部悬浮工具栏；「视图」按写作模式保存多套布局。

## 开始使用

当前维护版本为 **0.1.2 Windows 桌面版**。安装 Node.js 22.12 或更新版本后，在仓库根目录运行：

```powershell
npm ci
npm run desktop
```

`desktop` 会先构建客户端，再启动 Electron。需要生成 Windows 便携程序时运行 `npm run desktop:portable`；依赖、构建产物和运行数据不提交到源码仓库。原型浏览器版自 0.1.1 起冻结，后续以桌面软件为维护入口。

后台标签短暂隐藏后释放编辑界面，返回时保留本次运行中的正文、滚动和撤销记录；重复打开未变化的同文件保留原编辑状态，旧读取结果不覆盖后来编辑。版本维护记录见 [docs/record/版本维护记录.md](docs/record/版本维护记录.md)，代码原因、内存对照及验收边界见 [docs/performance-0.1.2.md](docs/performance-0.1.2.md)。本机专用的性能验证入口使用独立用户目录；完整极限集通过 [生成说明](performance/README.md) 在本地重建，仓库仅保留自动化测试必需的公式样例。

Windows 桌面版名称为 **HIVE markdown editor**。打包后可使用相应版本的 `release/HIVE markdown editor <版本>.exe`，或通过 **启动Windows版.cmd** 打开程序文件夹版。普通打包程序的文稿和设置仍在 `%APPDATA%\HIVE`；可在「我的写作空间」中选择自己的文档文件夹。

本批大表按可见行分段显示、连续滚动；超宽表保留完整可编辑源码并显示提示。超过 100,000 个字符的文档，全文和大范围选区统计在后台完成，期间显示“统计中”；规范大表的源码语法着色采用轻量轮廓，实时预览与 Markdown 原文保留。文件读取仍限 2,000,000 字节，尚不代表支持测试集中的 100 MiB 文件或达到常用环境 100 MB 内存目标。

Windows 版的「浮动面板」直接打开可移出主窗口的系统窗口，组合标签中仅分离当前标签；主界面不显示占位卡片。点击软件图标或再次打开程序会把主窗和所有已打开的浮动窗口恢复到前台。主窗口右上角提供同风格的最小化、最大化／还原与关闭按钮；浮动窗口不允许最大化，汉堡菜单提供最小化、移回或关闭。拖动标题留白移动窗口，从窗口边缘调整大小。关闭浮动窗口会先把面板移回；「关闭面板」则隐藏该面板。退出软件先保存正文、草稿与标注，保存失败或冲突时保留窗口。

开发时保留两个入口：**启动浏览器开发.cmd**（默认 `http://127.0.0.1:4318/`）和 **启动桌面开发.cmd**（Vite 热更新与真实系统窗口）。浏览器中的「浮动面板」保持页内浮动。

从源码开发时需要 Node.js 22.12 或更新版本，在本目录打开终端安装依赖：

```powershell
npm ci
```

安装开发依赖后可运行 `npm run dev`，或使用上述开发启动入口。`npm run desktop` 构建并运行桌面版，`npm run desktop:portable` 生成 Windows 便携包。旧的 **启动原型.cmd** 仍使用默认 4317 端口；同机保留旧版时使用新的 4318 浏览器入口。

打开文档即可开始写作；顶部「开始」提供一至四级标题、粗体、斜体、下划线、段落对齐、列表和浮动查找替换面板。右上角「面板」打开分类管理浮窗，按类别或搜索查找，点击名称即可打开并定位；双击工作面板标题栏可锁定或解锁位置，也可在设置 → 功能改用长按。「视图」可保存和应用布局。底部第一个按钮用于标注，另外三个图标只切换写作模式；中间 AI 按钮始终保留，点一下打开 AI 面板，再点一下关闭。初始为演示模式，可在右上角「设置」中连接自己的模型。AI 区的「依据」打开独立面板，管理参考资料并查看上一次请求的实际输入。

## 使用时注意

- 正文默认自动保存，也可使用 **Ctrl+S** 或顶部「保存」「另存为」。点击左上角「我的写作空间」可设置文档文件夹，外部文件变化会自动同步。
- 关闭或收纳额外正文、草稿面板时会释放编辑器视图；在当前页面重新打开，会恢复编辑内容和撤销历史。关闭面板不等于退出软件或刷新页面。
- AI 建议可以采纳、放弃或继续调整，也可以撤回最近一次 AI 修改。
- 刷新或退出前请保存正文。当前布局、对话和未保存内容还不能在刷新或重启后完整恢复。
- 浏览器版的工具面板在视口内浮动；Windows 版通过同一个「浮动面板」入口移出主窗口。输入法组词期间请先完成输入，再移动或关闭窗口。
- 合并标签后默认拖动整组；选中标签后，汉堡菜单同时提供整组操作和当前窗口的单独操作。浮窗随操作置顶，左右折叠栏在下方，底部 AI 导航栏保持在浮窗之上。

侧栏图标单击临时展开；长按后可拖至左右任一侧的上半区或下半区，各区从上到下顺排。向工作区内拖出一段距离，出现提示后松手即可创建就近分区，也可从汉堡菜单选择「打开面板」。左侧图标在左侧打开、右侧图标在右侧打开。也可直接拉侧栏内缘，按上下半区展开为固定分区及标签组；设置 → 功能可调整圆形/长条拖动标识、长按时间及最短触发时间。

所有工作面板使用一致底栏。右键「查看文本标注」打开局部要求窗，左下「全局标注」可进入完整列表。
