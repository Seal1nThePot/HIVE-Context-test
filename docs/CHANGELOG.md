# HIVE 更新日志

## 0.1.5 内存与同步优化

- 仓库目录快照共用缓存和更新任务，未变化的同步响应省略整棵目录树；手动刷新、外部文件变化和低频校验更新快照。
- 扫描跳过依赖与本工程生成目录，按固定批次处理文件属性，限制驻留索引和监听数量。仓库切换后释放旧索引资源。
- 文稿同步使用有界属性/哈希提示，减少未变化正文的重复读取，保留定期内容核验及保存前完整冲突检查。
- 创建时间状态复用有限缓存，磁盘元数据被移动、恢复或替换后重新读取；失败时丢弃未提交缓存。
- 文件列表复用排序、筛选与路径索引；同步按请求完成后调度，仓库切换和手动刷新使迟到结果失效。
- 主题按样式表复用编译结果，浮窗增量镜像样式，退出时回收监听、动画帧与镜像节点。
- 从 0.1.4 独立整理源码，移除历史交付副本、旧发布产物和临时诊断脚本，开发与日用资料使用独立目录。

## 0.1.4 整合构建

本节记录统一主工程中的 0.1.4 整合内容。正在运行的版本、构建编号、渠道和时间请查看“设置 → 关于”；历史独立工作组包不代表当前主工程的全部成果。

- 表格移除常驻顶部按钮栏，改用右侧/下方悬停添加、行列选择与右键删除；普通矩形选择、行内 Markdown 预览、长格完整显示及分栏逐行对应同步修复。
- 标题旁增加章节折叠，分栏两侧同步；引用竖线移近文字。代码块保留换行并支持 Shift + 滚轮横移，接入常见已支持语言的实时语法着色；长技术字符串可提前折行。
- 当前行和输入光标提高可见度，链接增加独立文字色和仓库文件右键跳转。桌面文件定位改为原生资源管理器调用。
- 文件树避免逐个检查非 Markdown 文件，并限制并发扫描；删除成功后撤离对应正文会话，避免错误保留为未命名稿并反复要求保存。
- 新增“设置 → 关于”：展示版本、构建、渠道和运行环境，内嵌离线帮助、更新日志及许可证；诊断先预览后复制，桌面支持打开应用数据目录。没有在线更新服务。
- 仓库管理成为独立面板，支持多个已有目录、备注名称、排序和切换；桌面添加仓库使用系统目录选择，取消不会写入登记。
- 文档面板支持文件夹折叠、排序及方向切换、多选与右键批量操作；回收站位于左下方，图片详情从更多菜单打开。批量动作逐项反馈结果，异步操作继续检查文稿与 AI 提案状态。
- 正文支持 Obsidian 图片引用、标准相对图片及引用式图片；待办可写回，新增共享文稿及撤销历史的左右分栏显示。表格快捷工具支持局部插删行列并保留相关格式与标注。
- 代码模式左侧显示逻辑行号；分栏源码跟随正文视觉断行，宽度超出时可横向滚动。显示层对齐不写入文稿，退出分栏恢复阅读排版。
- 中英文混排的普通自动折行尽量两端对齐，长网址、路径和极长英文串单独处理，普通英文词保留自然字距；左对齐命令明确保存选择。
- 文字颜色可手动调整，个人配色按模板与基础色隔离；停靠引导、落位预览和拖放提示采用共享主题配置。
- 外观设置新增“文本编辑页面”，集中调整页面背景、正文文字和 12 项编辑区颜色，其中 8 项高亮背景支持透明度；文本选区颜色独立于全局选中项目背景。
- 窗口生命周期集中处理浮动、收纳、回接与故障恢复；原生几何使用内容区域和缩放换算，避免反复开关引起尺寸与位置累积变化。

真实鼠标、中文输入法、跨屏与实际模型效果仍需按具体整合构建验收；源码和自动化检查不等同于这些操作已经完成。
