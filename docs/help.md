# HIVE 0.1.5 使用帮助

这份离线帮助对应 0.1.5 主工程的功能。实际可用功能以正在运行的构建为准；主工程源码更新不表示整合包已经发布。

## 文稿与仓库

点击左上角仓库名称打开仓库管理。可添加已有文件夹、备注名称、排列及切换仓库。移出列表只移除登记，不会删除仓库中的文稿；切换前先处理未保存内容和待审 AI 提案。

在文档列表中创建、搜索和打开 Markdown 文件。Ctrl+S 保存正文。文件可通过右键菜单重命名、移动、删除到回收站或添加为 AI 依据；Ctrl / Shift 用于多选和连选，批量动作位于右键菜单。回收站位于文档面板左下方。图片详情可从文档面板更多菜单打开。

## 编辑与显示

正文右上角的显示模式菜单提供实时预览、代码模式（Markdown 源码）和左右分栏。代码模式左侧显示源码行号；分栏中左侧为带行号的源码，右侧为正文，两侧共享同一份文稿与撤销历史。Ctrl+Z 撤销，Ctrl+Y 重做。Ctrl+F 查找与替换，Ctrl+H 在编辑区打开替换。

普通正文的中英文混排会尽量对齐两侧边缘，末行自然左齐；长网址和路径可在必要时折行。单个普通英文词独占一行时保留正常字距。明确选择的左、中、右对齐仍按各自设置显示。

左右分栏优先逐行对应：源码跟随正文的视觉断行，Markdown 标记额外占用的宽度可横向滚动。退出分栏恢复原来的阅览排版，不改变保存的排版参数或文稿换行。表格的表头、数据行分别对应源码行；语法分隔线保留独立源码行。图片和独立公式按对应源码区域整体显示。

Markdown 图片可点击揭示源码；待办复选框直接写回 Markdown。表格右侧、下方悬停出现加号，分别添加列、行；边缘圆点可选择整行或整列，选中后右键删除，表头和最后一列受保护。跨单元格拖动选择矩形，单元格内仍可选字。表格平时显示加粗、斜体、行内代码、链接等行内预览，双击或聚焦后按 Enter 编辑该格 Markdown，失焦恢复预览。公式需要多行时，在块公式中使用 aligned、gathered 或 cases 等环境。

标题旁箭头可折叠/展开该节内容，不改变保存的 Markdown。引用块的竖线贴近正文。三个反引号代码块和缩进代码保留原始换行、空格，超宽时横向滚动；Shift + 鼠标滚轮横移整个对应编辑区，代码各行同步移动。语言标记支持 JavaScript/JSX、TypeScript/TSX、HTML、CSS、JSON 和 C#（cs、c#、csharp）实时语法高亮；未知或未标语言保留普通代码。长技术路径可以提前折行，避免普通正文被过度拉伸。

文本编辑页面的当前行高亮和光标更明显；链接文字颜色可单独设置。仓库内链接可通过右键菜单跳转文件，仍经过当前文稿的保存检查。桌面“在系统资源管理器中显示”通过系统原生调用定位文件。删除成功后关闭对应正文；服务请求期间新出现的输入保留为独立未命名稿，以免丢失新内容。

## AI 协作

Ctrl+J 打开 AI 面板。在“设置 → 模型”配置自己的服务与模型；演示模式仅用于体验。检查当前模型和依据，再发送消息。AI 对正文的修改先形成提案，请审阅范围与内容后再采纳。续写最大字数可在“设置 → 写作”调整，默认 100 个可见字符。

生成过程中可按 Escape 停止。模型输出与实际写入结果需要人工检查。

## 面板与外观

通过面板目录打开工具面板。面板可浮动、停靠或收纳；标题栏双击或长按锁定的手势可在设置中调整。桌面子窗口关闭时按现有窗口规则移回主窗口，文稿会话继续保留。

在“设置 → 界面”调整编辑栏、字号和正文排版；在“设置 → 外观”选择模板、调整文字与停靠引导颜色。个人配色按模板与基础色保存；普通调色不会写入模板，只有模板管理中的明确保存动作会写入模板文件。

## 版本、帮助与诊断

在“设置 → 关于”查看当前版本、构建与运行环境，离线阅读帮助、更新日志及许可证。浏览器只提供粗粒度平台信息，无法确认系统架构；桌面信息读取失败时会标明回退来源。

诊断信息先展示预览，再由你选择复制；不会读取正文、聊天、模型配置、密钥或完整本机路径。桌面版可请求系统打开应用数据目录；该操作不复制目录路径。当前没有在线更新服务，更新由统一发布提供。

退出应用前保存文稿。跨启动的完整会话及撤销历史恢复不属于本帮助承诺的能力。
