## 0. 一句话结论

0.1.4 已经是一个**能日常写 Markdown 的编辑器**：磁盘优先的读写、自动保存、多标签、文件树与文件操作、回收站（预览→永久清理两步）、12 个可停靠/浮动/分组的面板、4 套配色模板 + 精细到控件级的颜色设置、以及一条**"AI 建议先审阅、采纳才落盘、可撤回"**的 AI 写作闭环（当前默认演示模型，无需密钥即可跑通）。

**还不能当"成品 Office"用**：新建/打开/导出/最近使用、文本插入、拼写检查、批注（新建与审阅）等仍是占位；真实模型需要自己添加服务。

**0.1.5 增量**（详见 §12）：模型目录获取与名称排序、推理档位 / 输入类型 / 服务默认强度设置、密钥本机持久化、回收站三级重构（行内永久删除）、外观设置分层、输入框阴影独立设置、AI 按钮流光、工作区对话保留、`treeVersion` 同步优化等已进入本版。

## 1. 三条真正闭环的主流程（本次重点验证）

### 1.1 编辑 → 自动保存到磁盘 ✅
- 在正文里输入，**≤2.5 秒**内磁盘文件更新（实测 `示例.md` 出现写入的段落 "这是 0.1.4 实测写入的段落，用于确认自动保存。"）。
- 顶栏"自动保存"开关默认开启，tooltip "自动保存已开启 · 点击关闭"。
- 底部栏实时字数：`33 字符 / 28 字`，可切换统计口径（字符 / 字）。
- 实现口径（源码 `src/features/files/useDocumentPersistence.ts`）：2 秒轮询 `/api/workspace/sync`，带 baseline 冲突检测。

### 1.2 AI 建议：审阅 → 采纳 → 撤回 ✅
1. 底部写作快捷栏切到 **往下续写**；对话面板 composer 里 `Enter` 发送（`Shift+Enter` 换行）。
2. 正文下方出现 **"AI 建议审阅"** 区：`待审阅建议` / `往下续写 · 53 字` / `定位正文` / `建议插入 · 实测标题` / 提示"采纳前，正文保持当前内容"，按钮 **继续调整 / 放弃 / 采纳建议**。
3. 点 **采纳建议** → 立即写入磁盘（追加 53 字段落），顶栏 **"撤回 AI 修改"** 由 disabled 变可用。
4. 点 **撤回 AI 修改** → 磁盘回滚到采纳前内容 ✅。
5. 没有真实模型也能跑：设置里"当前使用：**演示模式**"，回复形如 "【交互演示】这一轮可以先围绕「实测标题」…接入真实模型后…"（源码 `generateDemoText`）。

### 1.3 文件操作全链路（建/改名/复制/移动/回收/还原/清理）✅

界面上有：新建文档、新建文件夹、导入文件、重命名（F2）、删除到回收站（Delete）、复制路径、文件右键菜单（Shift+F10）、拖到空白处移至根目录。

后端经 `/api/explorer` 实测（响应原文）：

| 动作 | 请求 | 实测响应 |
| --- | --- | --- |
| 新建文件 | `{action:'create',type:'file',parent:''}` | `{"path":"新建文档 2.md","type":"file"}`（同名自动加序号） |
| 新建文件夹 | `{action:'create',type:'folder'}` | `{"path":"新建文件夹 2","type":"folder"}` |
| 重命名 | `{action:'rename',path:'新建文档 2.md',name:'接口改名.md'}` | `{"path":"接口改名.md","from":"新建文档 2.md"}` |
| 复制副本 | `{action:'duplicate',path:'接口改名.md'}` | `{"path":"接口改名 副本.md"}` |
| 移动 | `{action:'move',path:'接口改名 副本.md',parent:'新建文件夹'}` | `{"path":"新建文件夹/接口改名 副本.md"}` |
| 删除到回收站 | `{action:'trash',path:'新建文件夹/接口改名 副本.md'}` | `{"id":"0270c40c-…","deletedAt":"2026-11-17T17:56:20.765Z"}` |
| 回收站列表 | `GET /api/explorer/trash` | 两条记录（含 id/path/type/deletedAt） |
| 还原 | `{action:'restore',id:'…'}` | `{"path":"新建文档.md","type":"file"}` |
| 全文查找 | `GET /api/explorer/search?query=实测` | `{"matches":[{"path":"示例.md","line":5,"excerpt":"# 示例 正文。 ## 实测标题 …"}],"truncated":false}` |
| 清理预览 | `POST /api/explorer/trash/preview {days:30}` | `{"token":"6b1e…","days":30,"cutoff":"2026-10-18T17:56:31.234Z","expiresAt":"2026-11-17T18:01:31.234Z","items":[],"count":0}`（**token 5 分钟有效，必须先预览**） |
| 永久清理 | `POST /api/explorer/trash/purge {token}` | `{"deletedIds":[],"failed":[]}`；同一 token 再用 → **409** `回收站内容已变化或预览已过期，请重新预览并确认。` |
| 行内永久删除（0.1.5） | `POST /api/explorer/trash/delete {ids:[…]}` | `{"deletedIds":[…],"failed":[]}`（免 token，1–100 条；全部不在回收站 → 404 `这些条目已不在回收站中。`；实测 4415 通过） |

约束（源码 + 实测）：
- 只处理 `.md` 文件与文件夹；符号链接/目录联接一律拒绝。
- `自由草稿.md` 可以删除到回收站（删除后草稿面板显示为空，下次保存重建）；改名与移动仍由草稿面板管理。
- 文件夹不能移动进自身或子目录；目标已存在时 409。
- 回收站是 `<工作区>/.hive-trash/`：`<uuid>` 存数据、`<uuid>.json` 存清单；清理是"预览拿 token → 用 token 提交"，清单指纹变了就 409。

## 12. 0.1.5 增量（2026-11-19，隔离实例 API 实测 + 源码核对）

> 界面未逐项重跑（浏览器实拍本轮受阻）；逐条外观细节以 `docs/CHANGELOG.md` 的 0.1.5 各小节为准，此处只记结构性变化。

- **模型设置**：服务对话框「获取模型」→ 目录弹窗（搜索 / 刷新 / 勾选 / 已选 N/100 /「应用」）；每模型「显示名称 / 上下文窗口 / 最大输出 / 推理档位（上游声明 ∪ 手动勾选）/ 输入类型（文本 / 图片，随上游声明带入）/ 默认推理强度」；上限 40 服务 / 100 模型，模型行内可拖动排序。
- **推理档位**：`off / minimal / low / medium / high / xhigh / max` 七档 + `default`（`model-capabilities.mjs`）；发送时按服务能力映射 `reasoning_effort` / `reasoning.effort` / `thinking.type`；档位不可用返回 409。聊天框左下角为模型图标 + 四根短柱（当前推理档位），点击打开模型选择（`ChatComposer.tsx:28`）。
- **导入默认档位**：上游导入或换接口地址后无声明档位 → 默认启用 `low / medium / high / max` 四档（`modelConfig.ts:36 defaultImportedReasoningLevels`）；手动取消全部档位后不再自动回填。
- **图片输入**：发送含图片消息（user content 数组 ≤32 段）而模型未声明图片输入 → 请求前 415 拒绝并提示去「模型设置 · 输入类型」勾选。
- **密钥持久化**：`state/keys.json` 明文落盘（0o600 临时文件 + 原子改名）；重启不重填；地址变更 / 清除密钥即丢；`read()` 只回 `hasKey`。
- **回收站（三级重构）**：标题下一行工具（搜索、清理期限、排序、清理图标），列表行悬停 / 聚焦显示「恢复 / 永久删除」；新增 `POST /api/explorer/trash/delete {ids}` 免 token 单个 / 批量永久删除（`TrashPanel.tsx:72/:96`，实测 4415 通过）；`preview` 天数支持 `0`=全部。
- **输入框阴影**：设置 → 外观 → 输入框阴影，可调 AI 栏输入框阴影颜色 / 模糊半径 / 垂直偏移，带预览与恢复默认（`ThemeSettings.tsx:30` / `ComposerShadowSettings.tsx`）。
- **AI 按钮流光**：生成期间底部 AI 按钮流光；「减少动态效果」时改静态高光。
- **外观设置分层**：外观顶层只留模板管理 / 基础颜色 / 当前方案 / 默认方案 /「自定义配色」入口；十余段颜色收进子页面按主版面折叠（全局与文字 / 工作区与面板（含 AI 版面推理轨道三色）/ 文本编辑页面 / 顶栏与底部工具栏 / 设置与弹出框 / 停靠引导与拖放）。
- **仓库管理**：`repositories` 成为固定面板 id（`viewPresets` 已知集 11 项）；顶栏仓库入口带文件夹图标、边框与悬停反馈。
- **工作区对话**：同空间切换文稿 / 关闭最后一个标签后，对话记录与未发送草稿保留；无正文也可讨论；生成中切标签取消该次生成。
- **草稿删除与发送键**：文档树可把「自由草稿.md」删除到回收站；AI 输入框 Enter 发送 / Shift+Enter 换行（`Ctrl/Cmd+Enter` 别名，IME 守卫）。
- **启动配色**：桌面版启动先应用上次保存的配色，再显示窗口与加载页。
- **内存与同步**：`/api/workspace/sync` 带 `treeVersion`，相同版本的响应省略 `entries`。文件索引有界（每仓库 ≤1 在途扫描、缓存 25000 条 / 4M 路径字符）。
